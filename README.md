# buzzer
گزارش کار ازمایش  buzzer 

نام و نام خانوادگی:مبینا اسحاقی

استاد:اقای دکتر عباسی

عنوان آزمایش:  buzzer 


هدف آزمایش: 
هدف از این آزمایش آشنایی با نحوه اتصال و استفاده از buzzer به برد آردوینو و توانایی تولید صدا با استفاده از این قطعه است. 🎯

وسایل مورد نیاز:
برد آردوینو (Arduino Uno) 💻
buzzer 🔊
سیم‌ها 🔌

لپ تاپ یا کامپیوتر برای برنامه‌نویسی آردوینو 💻

نرم‌افزار آردوینو IDE 🖥️



شرح آزمایش:
اتصال buzzer به برد آردوینو:

پایه مثبت buzzer به پایه دیجیتال 8 آردوینو وصل می‌شود. ⚡️

پایه منفی buzzer به پایه GND آردوینو وصل می‌شود. 🔴

نوشتن برنامه: در نرم‌افزار آردوینو IDE، برنامه‌ای نوشته می‌شود که buzzer را روشن کرده و صداهایی تولید کند. برای این کار از توابع tone() برای ایجاد صدا استفاده می‌کنیم. 📟

تست و مشاهده: پس از ارسال کد به برد آردوینو، buzzer باید صدایی با فرکانس مشخص تولید کند. در این مرحله می‌توانید فرکانس‌های مختلف را تست کرده و مشاهده کنید که صدا تغییر می‌کند. 🔄

نتیجه‌گیری: این آزمایش به شما کمک می‌کند تا نحوه استفاده از buzzer با برد آردوینو را یاد بگیرید و بتوانید در پروژه‌های مختلف از این قطعه برای تولید صدا استفاده کنید. ✅
